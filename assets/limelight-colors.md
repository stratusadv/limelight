## Mono

A mono file without a ground fills each shape with `currentColor`, so an inline copy takes the color of the text around it. The mono mark separates the face from the two bands with a narrow gap, because a single ink cannot tell them apart by color. The compact mono mark widens that gap so the cuts stay visible below about 48 pixels.
